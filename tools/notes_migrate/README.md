# 笔记迁移（按页面几何，一条命令）

把用户确认过的快照页上的手写笔记，搬到新版页面上。不叠规则、不靠运行时模糊匹配：
**笔是怎么画在旧内容上的，就怎么画在新内容上。**

```
python3 tools/notes_migrate/run.py snapshot/2/week3_4.html <新版 week3_4.html> preview/3/week3_4.html --assets-prefix ../2/
```

退出码 0 = 核对 0 错。`build_tmp/notes_migrate/` 里有：
- `week3_4.notes.json`：迁移后的笔记，直接作为笔记仓库的 `notes/week3_4.json`（`updatedAt` 已更新，同步合并时会覆盖旧锚点）
- `week3_4.report.txt`：每组笔的结论（same / partial / rephrased / figure / gone）和隐藏原因

依赖：playwright（Chromium）、opencv-python、numpy。连不上 jsdelivr 时设 `NIPC_MATHJAX_DIR=<mathjax@3.2.2 npm 包目录>`。

## 算法

1. **量两版几何**：同一个无头 Chromium、同一宽度打开两页，展开全部折叠，按笔记层同样的规则建正文文字索引，
   量每个字、每个公式符号（MathJax `data-c`）、每张图的矩形。旧页上每一笔的位置取笔记层自己画出来的（即用户确认过的样子）。
2. **一次全局 diff**：正文字 + 公式符号按文档先后排成一条记号流，旧版对新版做 diff。原样保留且所在原样段 ≥ 4 个记号的，
   才算「同一个内容」；前后都没变的一对一短替换（d → δ）也算。字母换名表（t → q、θ → ψ）从全页 diff 里统计出来，不用手写。
3. **一笔压住了什么**：中心落在笔画外框里的记号；没有（下划线、旁注）就取最近那一行 / 那一个，再加外框外一行内的记号一起投票。
   连着写的几笔（1.5 s 内且相距 25 px 内，或钢笔笔画相距 6 px 内）并成一组，一起平移、一起显示 / 隐藏。
4. **决定位置**（每组）：
   - 压住的内容大多在原处可信地对上，且平移量一致 → **整组刚性平移**（same / partial）。
     原锚点本身也对上时，笔的存储坐标**一个字节都不改**，只换锚点前后文——在用户 iPad 上与快照完全一致，和服务器字体无关。
   - 对不上（改写）→ 在新版对应段（前后最近的没变内容之间，外扩一段）里找同一串内容，同一段里的几组一起按叙述先后单调对齐
     （动态规划）。单个字 / 符号要紧挨着的前后至少一个记号也对得上（rephrased）。
   - 段里没有 → 在新版新增的内容里全页找，前后文要像（moved）。
   - 都没有 → **内容没了，隐藏**（`anchor.gone = true`，运行时不画，不出现灰色笔）。
   - 图：文件没变就原样；重画了就每笔单独在新图里多尺度模板匹配笔下那块图，笔下内容对不上（标签删了）就隐藏（figure）。
5. **写锚点**：都是新版原文里一字不差的 TextQuote / 公式 TeX / 图片 src，运行时只走精确匹配，不会被运行时的模糊匹配挪走。

## 核对（不用迁移的结论）

`run.py` 写完预览页后再打开它，让笔记层自己画：
1. 每一笔实际画的位置 = 迁移算出的位置（差 ≤ 0.6 px），该隐藏的都隐藏；
2. 每一笔在新页上压住的内容 vs 在旧页上压住的内容：内容没变的笔必须一个不少；
3. 820（iPad 竖屏）、2048 宽度下两页各开一遍，再比一次压住的内容。

`selftest.py preview/3/week3_4.html`：把一笔右移 30 px，核对必须只报这一笔。

## 对说明里五个问题的回答

1. Hypothesis / W3C 的 TextQuote 适合「一段文字上的高亮」，用在单字、公式符号、手写旁注上区分不开候选。
   这里改成「全文 diff 的对应关系 + 几何平移」：定位靠整页的对应，不靠一个字的前后文打分。
2. 规矩 3–5：diff 认得出的直接跟着走；改写的段落在对应段里按关键词找，几组一起单调对齐。
3. 单字 / 单符号：几乎都在 diff 的原样段里，直接对上，不用在几百个候选里挑；在改写处才要求紧挨着的记号也对上。
4. 核对在另一次打开的预览页上量，和迁移的推断无关。iPad 与服务器的字体差别：内容没变的笔坐标原样保留，不经过服务器排版；
   公式整体挪动（缩进、换框）的平移量与字体无关。只剩改写处的少数笔用服务器排版换算。
5. 内容没了就隐藏（规矩 2）；内容还在就放到它上面，不另标。隐藏的每一笔在 report 里有原因。
